## 3. Fixes (data layer)

1. **Normalise plan-item leadership.** Split `PlanItem.leads` into `leads` (the handbook's task leader or deliverable lead only) and `listed_in_leadership` (website Leadership lists). Link `HoldsRole task_lead` rows to the PlanItem (`WorksOnPlanItem role='lead'` from the handbook table) and add `lead_organisations` (normalised org ids). Then "which tasks does Tartu lead" is one query that returns empty, and the plan rows show Earlham/UiB/biodata.pt/UiT as task leaders instead of 12-21 names per task.
2. **Per-initiative "not public" record.** Add `Initiative.not_public` (or a `coverage` SourceStatement kind) from sources that state it: for STEERS, from D1.6 §6.1 "Grant Agreement, DoA (tasks, partner roles, person-months, budget) on the internal STEERS Google Shared Drive", plus the project-wide rule that person-months are rarely published. Expose it in `/api/initiative`. This also covers 008 c5 and 009 c4.
3. **Smaller views.** `/api/initiative?id=initiative:steers` is 849 KB (542 plan items, 552 roles). Add `?sections=` or a role summary grouped by work_item, so `roles` gets read at all.
