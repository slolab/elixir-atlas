3. **Extract the Communities Handbook body** as statements on the ELIXIR Communities initiative: joining route, roles, liaison, Slack, and the "How to join" guides with links. This also serves 003.
4. **Make query rows narrower.** Agents repeatedly join wide Initiative text onto every child row. A view that returns plan items without repeating the parent fields would keep evidence inside the print budget. The skill could also say this.
