## 2. Root cause of the missed component

**Component 1: HARD_TO_REACH (missing Organisation→Node edge; path undocumented).**

Checked (graph.sqlite):

- `SELECT ... FROM TakesPartIn t JOIN Initiative i ON i.id=t.target WHERE t.source='node:estonia'` → 27 initiatives; the only `eu_project` is `initiative:converge` (4 edges, from the CONVERGE WP pages). No edge to `initiative:steers` or `initiative:excelerate`.

- No edge links any Organisation to an ElixirNode (no such table). The only join is `Organisation.country = ElixirNode.country`, which returns exactly the three projects for Estonia (`... JOIN Organisation o ON o.country=n.country JOIN ParticipatesIn p ... WHERE n.id='node:estonia'`). ASSUMPTIONS.md calls this a known gap ("Organisations are not linked to Nodes"), but that file is not given to the agent.
- University of Tartu is split over four Organisation rows: `tartu-ulikool` (CORDIS), `university-of-tartu`, `university-of-tartu-ut`, `utartu` (EE-UTARTU). People (Hedi Peterson, Uku Raudvere, Diana Pilvar, Kaur Alasoo, Heleri Inno) are `AffiliatedWith` the non-CORDIS rows; `tartu-ulikool` has **zero** AffiliatedWith edges, so Person→Organisation→ParticipatesIn also breaks. ## 4. Other data problems seen (no points lost, but risky)

- **DATA_WRONG canonical dates (systematic).** For every Estonia service that also has an ELIXIR-UK Node page, `Initiative.start/end` equals the UK page's dates, not the ELIXIR main page's, against the ASSUMPTIONS rule "start and end come from its main page".
