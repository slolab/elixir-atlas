## 4. Fixes, most likely first

1. **Add a derived `GroupActivity` table**, one row per dated item per group: `(initiative, date, precision, kind [own_output|meeting_held|meeting_announced|report_mention|project_listing|plan_item], own_or_indirect, item_id, title, source_url)`. Add `latest_own_activity` and `latest_evidence` (with date and item) on Initiative. This answers the A2 family in one query and puts the definition (own versus indirect) in the data, not in each agent's head.
2. **Fix the F1000 extractor** (`scripts/catalogues.py::f1000`). Read the abstract from `div.abstract__content` and link group authors in `creator_names` to their Community (a new OutputOf basis `author`). This restores links for most of the 88 unlinked recent outputs.
3. **Fix the list-mention matcher** so "the A, B and C Communities" links A, B and C, not only C.
4. **Date the documents.** Set `SourceDocument.published` for F1000 and Zenodo PDFs from the matching Output, and add a SourceDocument → Output link. Give each PlanItem a date precision and, where the text names a dated event ("All Hands Meeting"), a link to that Event.
5. **Align the guidance with the evidence model.** Say in api.md that a project page's first publication date is a valid "named on" date for the groups it lists, unlike `modified`.
