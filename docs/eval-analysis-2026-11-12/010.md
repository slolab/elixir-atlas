## 3. Fixes (data layer)

1. **Cross-project links on plan items.** Add a `related_work` field to the plan-item extraction (target project, target code such as "WP4 Task 4.1", relation such as complements/builds_on/delivers_for, verbatim quote). Emit `PlanItemRelatesTo(plan_item → plan_item | initiative)` with the quote. For this question that gives TP WP4 → STEERS T4.1/T4.3 and TP WP3/Activity 2 → STEERS T4.1/T4.2/T4.3, each sourced. The same field serves every "where is the overlap written down" question.
2. **Give RelatedTo an `evidence` quote and a `relation` value** (mentions, complements, parent, partner, successor). The existing 2024-training↔steers edge would then carry "clear complementary links to ELIXIR-STEERS WP4 ...".
3. **Attach "related" statements to the source project as well**, or at least name the WP in the evidence. A statement from the TP plan about STEERS should be findable from `2024-training`, not only from `steers`.
4. **Overlap view.** `/api/overlap` covers shared leaders only. Add `/api/initiative/overlaps?id=` that returns stated links (`PlanItemRelatesTo`, `RelatedTo` with quotes) separately from people shared on related plan items (with their Node). That answers components 1-3 in one call.
