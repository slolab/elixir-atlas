# AGENTS.md
- Before implementing something, align with the user using the grilling skill.
- When reporting to a user, use the reporting skill.
- Follow [the access control and group management policy](docs/access-control.md) when changing identity, membership, permissions, or access to data.
- It's a hackathon project, so we should keep the things simple and minimal. Actively prevent, catch, and combat overengineering. Feel free to break, rewrite an change stuff, there's no backward compatability or maintanance requirement.
- **Zero comments policy.** Code must be self-explanatory: no comments, no docstrings. The only exception is for extreemly non-trivial tricks or workarounds.
